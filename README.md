# Pipeline ETL de Vendas com Python e PostgreSQL

## Sobre o projeto

Projeto de Engenharia de Dados desenvolvido para estudar e demonstrar a construção de um pipeline ETL utilizando Python, SQL e PostgreSQL.

## Objetivos

- Extrair dados de arquivos CSV
- Validar e transformar os dados
- Carregar dados em PostgreSQL
- Executar consultas analíticas
- Implementar testes
- Documentar o pipeline

## Tecnologias

- Python
- Pandas
- PostgreSQL
- SQL
- Pytest
- Git
- GitHub
